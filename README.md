# 知行传播｜中小企业 AI 多平台传播工作台

这是一个为 AI 应用创新比赛准备的本地 Web 原型。它把企业素材、跨平台文案创作、拟真预览、发布排期和传播报表放在同一个工作台中。项目使用 Next.js App Router，进入 `ai-workbench` 目录后运行 `npm install` 和 `npm run dev`，即可在本机打开 `http://localhost:3000`。

第一次参与开发，请先阅读 [团队使用说明](docs/TEAM_GUIDE.md)。其中写明了功能、设计思路、各自负责的目录，以及拉取、提交和上传代码的步骤。具体的本地运行与环境变量说明见 [项目说明](ai-workbench/README.md)。

仓库根目录用于团队协作文件；网页源码位于 `ai-workbench/`。预设案例与演示结果可在没有大模型密钥时使用。数据看板显示模拟数据，“模拟已发布”只表示本地排期状态。
