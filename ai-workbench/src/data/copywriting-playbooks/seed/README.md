# 种草型写作大纲

## 一、传播目标

让目标受众快速判断“是否适合我、为什么值得试、如何开始”。种草型不是堆卖点，而是降低体验不确定性和决策成本。适合新品试用、功能介绍、场景解决方案、选购指南、组合推荐和促销转化。

## 二、写作前素材

- 目标人群：处于什么状态、有什么限制，而不仅是年龄和职业。
- 使用场景：何时、何地、与谁一起使用，前后还有哪些动作。
- 核心痛点：现有做法哪里麻烦、浪费、尴尬或不确定。
- 选择标准：受众真正会比较的三项以内指标。
- 体验证据：参数、成分、尺寸、流程、时长、适用条件或可演示结果。
- 使用门槛：价格区间、学习成本、维护方式、不适用情况。
- 行动条件：购买、预约、试用或了解下一步所需的信息。

素材不足时，用“适合谁 / 不适合谁”的边界表达代替虚构体验和用户证言。

## 三、核心结构

1. **场景痛点开场**：说出受众正在经历的具体麻烦，让其快速自我识别。
2. **提出选择标准**：告诉读者解决这件事应该看什么，不急着亮品牌。
3. **引入解决方案**：说明产品如何嵌入原有流程，避免夸张的“彻底改变”。
4. **体验拆解**：按使用前、使用中、使用后呈现关键细节。
5. **证据对应卖点**：每个主要卖点配一个参数、动作、对比维度或使用条件。
6. **主动说明边界**：讲清适合谁、不适合谁，以及不能承诺什么。
7. **降低行动门槛**：给出清晰下一步，如收藏清单、查看规格、试用或咨询。

## 四、A/B 两种切口

- **A 版｜问题解决线**：从高频痛点进入，逐步验证解决方案，适合明确需求和转化目标。
- **B 版｜选购判断线**：先给选择标准，再把产品放进标准中检验，适合高考虑度或同质化品类。

两版应改变决策路径；不能只把“痛点开场”改成“清单开场”后复用同一正文。

## 五、跨品类替换槽位

- `[目标状态]`：受众正在做什么、受什么限制。
- `[高频麻烦]`：一个具体且常见的问题。
- `[选择标准]`：最多三个关键判断维度。
- `[使用步骤]`：产品进入场景的真实顺序。
- `[事实证据]`：参数、原料、工艺、流程或演示结果。
- `[适用边界]`：适合与不适合的人群或环境。
- `[低门槛行动]`：下一步最容易完成的动作。

## 六、平台改写

- 小红书：用“场景复盘 + 使用清单 + 适用人群”，避免伪装素人评价。
- 微博：一个痛点、三个判断点、一个结论，鼓励转发补充经验。
- 抖音/TikTok：先展示麻烦，再现场演示步骤和结果；镜头承担证据功能。
- Instagram：用轮播分别呈现场景、细节、步骤和边界，正文补足选择理由。
- Reddit：公开使用背景、比较标准和局限，邀请社区质疑或补充。
- Discord：提供抢先体验、FAQ 或投票，让社群选择最想测试的场景。

## 七、自检标准

- 开头是否能让明确人群快速判断“这说的是我”？
- 每个卖点是否对应一个事实或可演示细节？
- 是否说清使用条件和不适用边界，避免万能化表达？
- 是否区分真实体验、企业资料与推测，不伪造用户口吻？
- 行动邀请是否与当前决策阶段匹配，而非一律催单？
