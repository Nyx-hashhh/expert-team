# 三类宣发文案操作手册

本目录用于沉淀可跨公司、跨品类复用的文案逻辑。三种模式不是语气标签，而是三条不同的说服路径：

| 类型 | 核心任务 | 读者看完后的理想反应 | 主线 |
| --- | --- | --- | --- |
| [故事型](story/README.md) | 让信息被感受和记住 | “我记住了这个人、这个瞬间” | 人物 → 冲突 → 转折 → 余韵 |
| [种草型](seed/README.md) | 降低选择成本并促成尝试 | “这正好适合我的场景，我想试试” | 痛点 → 体验 → 证据 → 决策 |
| [品牌型](brand/README.md) | 建立长期认知和信任 | “我理解它为何存在，也愿意持续关注” | 立场 → 行动 → 资产 → 关系 |

## 共通底线

1. 只使用企业提供或可验证的事实，不虚构功效、销量、奖项、用户评价和行业地位。
2. 一篇内容只承担一个主要传播目标；公司介绍、产品卖点和促销信息不可平均用力。
3. 抽象判断必须有具体细节支撑，例如人物动作、使用场景、参数、流程、时间或来源。
4. 先形成平台无关的内容骨架，再按平台调整长度、节奏、互动方式和视觉提示。
5. A/B 两版必须更换核心切口或论证顺序，而不是只替换标题和形容词。
6. 避免“赋能、引领、匠心打造、重新定义”等空泛表达，避免整齐排比和强行升华。
