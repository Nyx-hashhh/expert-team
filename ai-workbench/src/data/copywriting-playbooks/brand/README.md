# 品牌型写作大纲

## 一、传播目标

回答“这个品牌为何存在、坚持什么、凭什么相信、未来想与谁同行”，建立稳定且可重复的长期认知。品牌型不等于公司简介，也不是把使命愿景写成口号。适合品牌发布、价值主张、周年节点、社会议题、产地与文化资产、组织能力和长期栏目。

## 二、写作前素材

- 现实问题：品牌希望改善的行业、生活或服务现状。
- 核心立场：面对取舍时坚持什么，又明确不做什么。
- 起点事实：创立背景、所在地、关键人物或真实契机。
- 持续行动：产品、流程、服务或组织如何反复兑现立场。
- 信任证据：时间、机制、标准、合作方式、公开数据或可核验成果。
- 独特资产：产地、技术、审美、社群、方法、渠道或文化积累。
- 未来关系：希望与用户、员工、伙伴和社区形成怎样的长期互动。

素材不足时，缩小到一个可证明的品牌原则，不虚构宏大使命和社会贡献。

## 三、核心结构

1. **从现实张力开场**：指出行业或用户生活中一个真实矛盾，不先喊使命。
2. **给出品牌判断**：明确“我们相信什么”，一句话只表达一个立场。
3. **解释为何形成这一判断**：用起点事实或长期观察建立因果。
4. **展示持续行动**：列出品牌如何在产品、服务或流程中兑现立场。
5. **提供信任证据**：把价值观翻译成标准、机制、细节或可核验成果。
6. **界定独特位置**：说明品牌选择服务谁、解决什么，同时承认边界。
7. **发出长期邀请**：邀请受众参与、监督或共同建设，而不是只完成一次购买。

## 四、A/B 两种切口

- **A 版｜立场证明线**：从一个行业矛盾切入，用连续行动证明品牌主张，适合建立专业与信任。
- **B 版｜资产生长线**：从产地、技术、审美或社群资产切入，展示其如何多年积累并形成差异，适合建立辨识度。

两版的共同核心可以一致，但论据体系必须不同：一版证明“为何可信”，另一版解释“为何独特”。

## 五、跨品类替换槽位

- `[现实矛盾]`：品牌看到但不接受的现状。
- `[核心立场]`：面临取舍时的明确判断。
- `[起点事实]`：这一判断从何而来。
- `[持续行动]`：立场对应的实际做法。
- `[信任证据]`：机制、标准、时间或成果。
- `[独特资产]`：难以快速复制的积累。
- `[长期邀请]`：希望受众怎样参与品牌关系。

## 六、平台改写

- 小红书：用品牌幕后、主理人选择或产品原则呈现立场，少写完整企业履历。
- 微博：围绕一个公共议题表达清晰观点，用事实链接品牌行动。
- 抖音/TikTok：让流程、人物和地点证明主张，旁白只负责连接证据。
- Instagram：建立一致的视觉母题，以系列帖子持续展示品牌资产。
- Reddit：公开品牌正在解决的问题、决策依据和局限，接受社区追问。
- Discord：把价值主张转化为社群规则、共创计划、透明进度和长期栏目。

## 七、自检标准

- 全文是否能提炼出一句清楚、可被反驳的品牌立场？
- 立场是否被持续行动和证据支撑，而不是停留在价值词？
- 内容是否说明“不做什么”，从而形成真实边界？
- 独特性是否来自长期资产，而非“高端、专业、年轻化”等通用标签？
- 结尾是否建立长期关系，而非把品牌宣言突然变成促销口号？
