# Copywriting 目录协作说明

## 一句话理解

`idea` 负责想清楚“写什么”，`post` 负责把已确认的思路写成“适合哪里发布的文案”。两阶段只通过“所选模式 + 四字段思路 + 真实素材”交接。

## 目录结构

```text
copywriting/
├─ idea/                         第一阶段：简短输入 → 思路大纲
│  ├─ 01-methodology/            通用转译方法与调试方法
│  └─ 02-modes/                  故事型 / 种草型 / 品牌型，只选一个
└─ post/                         第二阶段：思路大纲 → 最终文案
   ├─ 01-foundation/             真实性、证据、素材和通用边界
   ├─ 02-categories/             品类事实与风险
   ├─ 03-platforms/              平台结构、语种、长度和互动
   ├─ 04-tones/                  表达距离、节奏和情绪
   └─ 05-composition/            组合、A/B 版本和成稿终检
```

## 协作时只记住四点

1. `idea` 只输出四行：核心宣发受众、核心表达、内容切口、开场钩子；不写正文、平台版本、语调或 A/B。
2. 四字段限制为 `10 / 20 / 25 / 25` 字，合计不超过 80 字；素材没有的内容用占位符或标记缺口，不要猜。
3. `post` 不重新发散思路：先读上游四字段，再按“基础 → 品类 → 平台 → 语调 → 组合”生成正文。
4. 每次只读取当前任务需要的一个模式、一个品类、目标平台和一个语调；不要把同级文件全部塞进提示词。

## 最容易出错的地方

- 不要把 `idea/02-modes` 当成最终成文模板；它只负责三种思路的差异化推导。
- 不要让平台热词或语调改变事实、证据和已确认的核心表达。
- A/B 版本在 `post` 阶段改正文路径或证明顺序，不改上游四字段。
- 修改目录编号后，必须同步检查 Markdown 相对链接。

详细规则以本目录各级 `README.md` 为准；本文件只用于快速分工和交接。
