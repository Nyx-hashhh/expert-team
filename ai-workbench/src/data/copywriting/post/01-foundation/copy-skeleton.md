# 核心文案撰写骨架

生成任何文案前，先过一遍这四件事：**定位 → 料 → 骨架 → 规矩**。定位见基础层 README；本文规定"料"与"规矩"。

## 一、料（素材六要素）

以下六要素用于确认产品和事实边界，是候选信息池，不等于每项都必须进入正文。缺失信息不虚构，也不机械补一句“以实际页面为准”：

| 要素 | 说明 | 示例（春茶） |
| --- | --- | --- |
| 品牌 | 企业名与一句话身份 | 日照绿茶案例，参考山东日照茶区资料；具体品牌待确认 |
| 型号/SKU | 具体到可下单的那一款 | 资料未提供，发布前待补充 |
| 产品名 | 用户口中的叫法 | 日照绿茶；具体款式待确认 |
| 受众 | 具体人群与其处境 | 在办公室泡茶的上班族；选山东伴手礼的人 |
| 场景 | 真实使用场合（时间/地点/动作） | 办公室泡茶；春季拜访时携带礼盒 |
| 核心参数 | 可核验的数字与规格 | 采摘时令、等级、净含量和认证以具体产品资料为准 |

**用法规则**：
- 先确定单一主张，再从六要素中选择能支持它的内容；禁止集中罗列成"产品档案"。
- 参数最多保留 3 项进入正文，且每项只表达一次；其余留给图表或评论区追问。
- 受众要写成处境而不是标签："连续加班第三周的文案" 优于 "都市白领"。
- 若案例素材缺某要素：优先补充事实；与本篇无关则直接省略，确实影响判断时才使用一次简短的条件化表述。

## 二、规矩（平台输出规范）

各平台的字数区间、语种、加粗、emoji 与输出格式，生成时严格执行：

| 平台 | 字数区间 | 语种 | 关键词加粗 | emoji | 输出格式 |
| --- | --- | --- | --- | --- | --- |
| 小红书 | 标题 ≤ 20 字；正文统一3–4个空行分隔的内容区块；常规180–350字、故事型最高450字，公告或纯情绪内容可更短 | 中文 | 正文禁用一切 markdown 记号（**、# 等），强调用直角引号「」 | 按实际情绪或分区需要使用，密度不超过每 40 字 1 个 | 标题 + 3–4段正文 + 5–9 个相关话题标签 |
| 微博 | 正文 100–140 字 | 中文 | 不加粗 | 至多 1–2 个点缀 | 短段落 + 2–3 个话题词（#话题名# 前后闭合，上限 5）+ 一句可讨论的收尾；购买链接一律文末且配利益点，不做裸链；型号/SKU默认不输出 |
| 抖音 | 标题 ≤ 20 字；口播稿 80–150 字；分镜四段：0–3 秒钩子 / 3–10 秒人物与需要 / 10–25 秒证据推进 / 结尾金句 + 讨论接口 | 中文 | 分镜关键词 | 标题可带 1 个 | 标题 + 连贯口播稿 + 分镜表（时间/画面/口播/BGM）+ 3–5 个标签；单镜 2–3 秒，每隔 3–5 秒一个小亮点 |
| IG / Facebook 联合发布 | 共同 Caption 50–120 词 | 英文 | 不加粗 | 3–6 个 | 两端原样同步同一份 Caption + 5–10 个 hashtag + 保存/评论/分享引导；型号/SKU默认仅留在产品图或购物标签 |
| TikTok | 标题 ≤ 50 字符；Caption 15–30 词；总口播 15–30 词；单镜字幕 ≤ 6 词/2 行；单镜 voiceover ≤ 12 词；时长 8–18 秒优先 | 英文 | 不加粗 | 0–2 个 | 3–5 个镜头只讲一个卖点；画面优先，背景与参数移至置顶评论或商品页；3–5 个标签 |

**通用规矩**：
- emoji 是节奏工具不是装饰密度竞赛；中文平台克制使用，海外平台按社区习惯。
- 小红书正文禁用一切 markdown 记号，强调一律用直角引号「」；微博、抖音、IG / Facebook、TikTok 不加粗。
- 语种铁律：小红书/微博/抖音中文；IG / Facebook、TikTok 英文，仅品牌名、地名保留专名。
- 输出格式必须完整（含标签/分镜等结构），字段不缺省。
- 小红书与抖音形态由主导价值、叙事模式与素材共同决定；A/B 两版选择不同主线、候选要素组合或证明路径，不为差异强套不合适的形态。具体选型见 [平台规则](../03-platforms/)。

## 三、骨架（组装顺序）

1. 读取上游已确认的“所选模式 + 四字段思路”，锁定受众、核心表达、内容切口和开场钩子；不得重新生成思路。
2. 抽取素材六要素确认具体产品，围绕单一主张挑选必要事实；型号/SKU仅作内部识别，除非用户明确要求区分易混款式，否则不进入正文。
3. 从 [品类规则](../02-categories/) 的故事节点、体验节点或品牌证据中选择最少但足够的组合，不按清单补齐。
4. 为参数、动作、感官、人物信息和判断分配唯一落点，再按 [平台规则](../03-platforms/) 决定字数、语种、格式与排版。
5. 使用 [表达语调](../04-tones/) 调整语言距离和节奏，不改变事实与已确认思路。
6. 交稿前过 [组合与终检](../05-composition/final-checklist.md)，任何一句"删掉也不影响理解或判断"的句子直接删除。
