# 02｜品类规则

品类层负责决定“需要哪些事实”和“怎样证明”，不负责决定全文骨架。

- [农产品](agricultural-products/)：产地、品种、时令、生产、分级、物流、风味与储存。
- [非遗产品](intangible-heritage-products/)：技艺来源、传承关系、材料、工序、当代使用与文化准确性。
- [美妆](beauty/)：肤质/发质、配方、质地、场景、使用周期、功效证据与个体差异。
- [日用品](daily-necessities/)：空间、动作、材质、结构、耐用、维护、安全与长期成本。

每个品类目录内按故事型、种草型和品牌型分别给出创作方法。
