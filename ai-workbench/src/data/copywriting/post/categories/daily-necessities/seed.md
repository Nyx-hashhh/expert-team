# 种草型 × 日用品

## 分享者与口吻

从真实家庭结构、居住空间、工作方式或通勤习惯出发，分享一个物品怎样减少重复麻烦。表达要朴实具体，让朋友看完就能判断尺寸、场景和使用成本是否适合自己。

## 体验结构

1. 写原来的小麻烦和使用环境。
2. 交代选择标准：尺寸、材质、操作、耐用、清洁、补充成本等。
3. 记录开箱、安装或第一次使用的难易度。
4. 在高频场景中连续使用，按动作讲体验。
5. 用时间、步骤、空间或维护变化证明优势。
6. 说明适合的家庭/空间、购买规格、维护方法和使用限制。

## 小品类思路

- 清洁用品：围绕具体污渍、材质、用量和步骤演示。
- 收纳用品：提供空间尺寸、摆放前后和拿取动线。
- 厨房用品：记录备餐、烹饪、清洗完整流程。
- 家纺个护：记录触感、吸水/透气等实际感受和清洗变化。

## 可信证据与禁区

不使用摆拍制造不真实效果；承重、耐热、抑菌、去污率等必须有数据来源；涉及安全时不得用个人体验替代标准说明。
