# 03｜平台规则

平台层负责信息结构、内容长度、视觉关系和互动方式。它不能改变核心事实，也不能替代叙事模式。

- [小红书](xiaohongshu.md)
  - [小红书爆款案例档案](xiaohongshu-cases.md)（写作参照，非平台规则）
- [微博](weibo.md)
- [抖音](douyin.md)
- [Reddit](reddit.md)
- [Discord](discord.md)
- [Instagram](instagram.md)
- [TikTok](tiktok.md)

小红书、微博、抖音固定使用中文；Reddit、Discord、Instagram、TikTok固定使用自然英文。海外平台可保留品牌名、地名等必要专名，但标题、正文、标签和分镜的其余内容必须保持英文一致，不因中文宣发诉求而改成中文。
