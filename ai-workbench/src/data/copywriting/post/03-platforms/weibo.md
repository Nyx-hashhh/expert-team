# 微博

## 平台任务

在较短阅读窗口内交付一个清晰信息点、事件节点或可讨论观点，促成转发、评论和话题扩散。

## 原生结构

1. 首句直接给出事件、观点或反差。
2. 用一至三段交代事实与核心证据。
3. 保留一句可被引用或讨论的判断。
4. 结尾提出具体问题或给出明确行动入口。

## 排版与元素顺序

单条微博按「钩子首句→正文→金句/讨论点→话题→@→链接」顺序组织。蹭热点或参加品牌活动时，热点话题可前置到首句之前（话题聚合页会给更好的展示位）；@与链接不进正文中间，避免打断阅读动线。

## 话题标签规则

- 格式为 `#话题名#`，前后都要闭合，缺后一个 # 话题不生效。
- 数量2–3个，上限5个：热点/活动话题1个 + 品类话题1–2个。
- 位置三分法：热点/活动话题前置（首句之前或首句内）；品类/长尾话题放文末集中放；话题也可自然嵌入句中（如「今天泡了 #日照绿茶#」），嵌入式最不像广告。
- 不蹭与内容无关的热词，热点相关性必须真实。

## @与链接

- @ 是联动曝光不是装饰：@ 官微、合作方、达人须与内容强相关，放在相关陈述句尾或文末集中放，全文不超过2–3个；@ 无关账号会被视为骚扰。
- 购买链接一律放文末，前面加一句利益点说明（如「戳这里👇 明前头采最后一批」），不做裸链接；优先微博橱窗、小店等站内链接，外域链接会被压缩成短链且部分平台有展示限制。

## 三种模式适配

- 故事型：选择五幕中的决定性瞬间，形成“微型故事”，不能把长文硬塞进单条微博。
- 种草型：一个痛点、两三个体验事实、一个适配结论。
- 品牌型：围绕品类议题表达立场，并立即给出行动或证据。

## 产品名称与型号

- 产品名只在事件、动作或使用场景中自然出现一次，不把正文写成产品资料卡。
- 禁止“产品名是……”“型号是……”“SKU为……”等命名陈述。
- 型号、货号、SKU和内部编码默认仅用于素材识别，不进入标题、正文或话题。
- 只有用户明确要求比较多个易混淆款式，且编号对购买判断不可替代时，才可在文末括注一次；能用容量、色号、版本、适用场景或自然产品名说清楚时，不写编号。

## 注意事项

热点相关性必须真实；话题标签少而准确；长信息可拆成线程，但每条都应独立提供信息价值。转发语要能独立成条——提供新角度或新情绪，不是复读原文。发布前删除所有不影响理解的型号与内部编码。
