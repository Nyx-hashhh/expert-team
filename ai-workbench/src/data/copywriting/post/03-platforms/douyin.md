# 抖音

## 平台任务

用前3秒可理解的画面或问题抓住注意力，再通过动作、场景、口播和节奏完成证明。镜头负责展示，口播负责因果，不让二者重复。

## 原生分镜

1. **0–3秒**：冲突、结果、异常细节或核心问题。
2. **3–10秒**：交代人物和场景，建立需要。
3. **10–25秒**：用过程、对比、操作或证据推进核心内容。
4. **25秒后**：给出适配结论、品牌记忆或互动问题。

## 开头3秒钩子库

5秒完播率是算法第一道闸门，钩子的本质是制造未闭合的信息缺口，六类任选其一：

| 钩子类型 | 原理 | 典型形态 |
|---|---|---|
| 视觉反差 | 违背第一预期，大脑强制停留 | 精致女神迈六亲不认的步伐（王七叶） |
| 悬念缺口 | 给结果不给原因 | 用最专业的运镜拍最糙的单身汉生活（张同学） |
| 痛点共鸣 | 3秒内让观众对号入座 | 「你有没有过…」句式 |
| 利益前置 | 承诺看完能得到什么 | 「最后一条值回全部」 |
| 强感官冲击 | 音乐、画面、动作的生理级抓取 | 重金属卡点开场（张同学《Aloha Heja He》） |
| 身份喊话 | 圈层召唤，无关者自然划走 | 「打工人都给我看这条」 |

钩子不是特效堆砌而是信息差：前三秒必须出现一个观众猜不到下一秒的东西。

## 节奏硬指标

- 分镜密度：单镜2–3秒为标杆（张同学平均2.27秒/镜，快于好莱坞的3–4秒），达不到就重拍重剪。
- 信息点间隔：每隔3–5秒安排一个小亮点（笑点、反转、新信息、画面变化），两个亮点之间的平段是跳出高发区。
- 张弛曲线：全程高能会疲劳，按「高—更高—回落—再拉高」安排，回落段用来铺垫下一次爆发。
- 音乐卡点：BGM是节奏骨架不是背景，画面踩点制造生理性爽感；固定BGM重复使用可形成账号听觉签名。

## 情绪触发点

- 反差是第一生产力：爆款脚本先回答「我的A期待×B呈现落差是什么」（诗意×卖货、精致×沙雕、专业×简陋）。
- 记忆点动作或台词：设计可模仿、可传播的社交货币（标志性舞步、口头禅、固定道具），让观众从观看升级为模仿共谋。
- 情绪要精确到一格：不写「好笑」「感动」，写「齁但心动」「上头停不下来」这类矛盾体感。

## 结构与结尾互动

整体遵循「钩子→高密度推进→反转或升华→金句收束」四段式，时间分配见「原生分镜」。结尾三件套：

1. **金句收尾**：结尾语是全片最易被截取转发的一句，值得单独打磨。
2. **动作收尾**：固定舞蹈或标志性动作是账号签名，也是二创素材。
3. **留讨论接口**：预埋「值得玩味但不给标准答案」的点，让观众有话可说；评论互动本身是算法加权信号。

价值密度足够高时结尾可省略引导（董宇辉大米文案让观众自发下单），但黄金句仍需保留。

## 三种模式适配

- 故事型：把五幕压缩成五个镜头节点，高潮必须可拍摄。
- 种草型：先展示麻烦，再完整演示使用过程和结果边界。
- 品牌型：让研发、工艺、人物、标准和地点证明专业，少用自夸旁白。

## 爆款案例参照

三例均经公开报道核实，学习方法论，不复制原句：

1. **董宇辉「大米文案」@东方甄选（2022.6）**：三个排比「我没有带你…」堆积亏欠感，一个「但是」兑换成购买力；参数全部翻译成画面（田间微风、智者般的谷穗）。爆因：对「宝宝们、最低价」话术审美疲劳的降维打击，叠加新东方转型叙事，单场观看771.7万、单日销售额1.7亿。
2. **王七叶「躲闪摇」系列（2022.4起）**：开场六亲不认步伐（视觉钩子）→闯关连环反转配《大风吹》卡点→土味情话金句+舞蹈收尾；大号酒杯等荒诞道具强化人设。爆因：清纯×油腻×自信大女主的人设差异化，魔性动作可模仿（火到TikTok、播放量破亿），团队用完播率/转发率/5秒完播率三指标数据化迭代。半年涨粉超千万。
3. **张同学「农村单身汉日常」（2021.10）**：7分钟218个分镜、固定BGM逐帧踩点、宝藏抽屉等固定元素形成连载感。爆因：专业运镜×简陋生活的终极反差、2.27秒/镜的沉浸节奏、#新农人计划流量扶持与人民网评背书。半月涨粉1125万。

## 注意事项

每个卖点必须有对应画面；禁止用夸张表演代替事实；口播适合自然短句，字幕补充参数与证据口径。案例台词仅用于方法论学习，创作内容必须原创，发布前人工审核合规性。
