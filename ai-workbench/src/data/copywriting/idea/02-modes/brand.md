# 品牌型思路转译

## 任务目标

将用户在工作台填写的【核心宣发诉求】作为本次传播方向，将当前勾选的【企业素材库】作为事实依据，提炼供下游写手扩写的品牌型思路大纲。本阶段只确定：**推广对象是谁 → 哪项特色值得记住 → 什么素材能支撑 → 对受众有何价值**。推广对象可以是企业品牌，也可以是有明确素材支撑的地方特产、非遗技艺或文旅目的地；没有企业品牌名时，不补造一个品牌。

遵循总 README 的组合顺序：`真实素材 → 宣发目标 → 叙事模式 → 品类证据 → 平台结构 → 表达语调 → 风险校验`。素材决定哪些特色可以说，用户诉求决定本次重点说哪一项。本文件只负责品牌型的认知定位和四字段思路；平台写法、语调、正文结构、购买引导与 A/B 成稿留给下游阶段。

## 输入优先级

1. **先读核心宣发诉求，确定本次要建立的认知**：提取推广对象、目标受众、希望突出的品牌特色、使用或出游场景及明确限制。诉求已经指定重点时，围绕该重点选素材，不因素材库里另有醒目数据就改换主题。
2. **再看本次勾选的企业素材，提取原初关键词**：优先使用与诉求相关的用户新增或上传素材，再从其他已勾选素材补充。区分对象词、特色词、支撑词、价值词和切入词；从中挑选一项核心特色及 1–2 个能说明它的具体细节。
3. **最后核对主张和证据**：区分可核验事实、企业自述、个人体验与参考文案的话术。诉求中提及的排名、认证、功效或效果仍须由素材证明。证据不足时缩小主张，保留有依据的品牌特色和受众价值，不补造权威背书或比较结论。

## 从原初关键词推导四字段

参考文案只提供提炼方法，不提供当前企业的事实。可复用的推导顺序是：**诉求选定特色 → 素材提取关键词 → 细节说明优势 → 优势转成选择理由 → 选择入口形成钩子**。不要把原文中的企业身份、地理标志、非遗认定、年限、功效、数据或口号直接移植到新任务。

### Step 1 识别推广对象和特色关键词

- 先确定本次推广的是企业品牌、具体产品、地方特产、非遗技艺还是文旅目的地。名称要与素材一致；不能把区域产品擅自写成某家企业的专有品牌。
- 从诉求提取一个最希望受众记住的特色，再在已勾选素材中寻找对应关键词：农产品可看品种、产地、时令、风味；文旅可看景观与参与体验；非遗可看技艺与当代用途；日用品和美妆可看材料、设计、产品体系及适用需求。
- “高端、专业、优质、值得信赖”不能单独充当特色。要找到能让人识别这个对象的具体信息；没有独特证据时，只表述素材确实支持的品类特点，不宣称超越同类。

### Step 2 将特色与证据连成选择理由

- 为核心特色选 1–2 个相关支撑词，如明确的工艺、纹样、产品类别、使用方式、可参与活动或已核实的标准。细节要能解释特色从何而来，避免把认证、仓储面积、销量等数字当作天然的用户利益。
- 再问：这些细节能让受众更容易识别、体验或选择什么？例如“鲁锦纹样与茶桌用途 → 传统织纹进入当代家居”；“水乳有不同系列与适用需求 → 便于按需求挑选”。不能从产品系列推导未经证实的护肤功效。
- 在多项优势中只选最贴合本次诉求、最有素材支撑、最容易形成清晰记忆的一项。其余信息可留给下游写手，不在四字段里并列罗列。

### Step 3 选择品牌型内容切口

- 内容切口用“**特色资产 → 具体支撑 → 受众价值**”说明这次准备怎样阐述品牌优势。资产可以是地方风味、技艺、景观组合、产品设计或选择方法；支撑必须来自当前勾选素材。
- 农产品可从“特定风味为何值得记住”切入；文旅非遗可从“地方或技艺的可识别之处如何进入当代体验”切入；日用美妆可从“产品或体系如何回应明确需求”切入。按实际诉求选一个，不固定套用某一类开头。
- 切口不是公司介绍目录、卖点清单、路线攻略或正文段落安排。若只有产地或产品名称，缺少可支撑的差异细节，就按已有事实写具体品类认知，不推断“最好、唯一、必买”。

### Step 4 压缩为四字段

- **核心宣发受众**回答“谁会在意这一特色或选择理由”。优先使用诉求明确指定的人群；否则从有依据的需求概括，不凭空添加年龄、身份或消费能力。无法合理细分时填写“泛消费人群”。
- **核心表达**回答“希望受众把推广对象与哪一项优势联系起来”。尽量同时写出对象和单一特色，表达可记住的价值，不堆叠口号、数据或多个卖点。
- **内容切口**回答“用什么具体素材说明这项优势”。用三个短语排列“特色资产 → 具体支撑 → 受众价值”；三个短语指向同一个核心表达，不扩写成提纲章节。
- **开场钩子**回答“从哪个具体信息进入这项品牌认知”。可选一个动作、地方习俗、用途反差、场景或问题；句式随素材而变，不必每次惊叹或提问。钩子与切口一致，不能另开一个未经证明的主张。四字段各回答不同问题，不把同一句卖点换词重复。

## 严格边界

- 只输出备忘录式品牌思路大纲。允许具体、自然的口语表达；不写正文、分段结构、企业履历、平台标题、购买行动、A/B 方案或完整品牌宣言。
- 只使用本次勾选的企业素材作为事实来源。参考文案中的比较、个人体验、地方身份、历史、产品效果与营销档期不能成为当前企业的事实；未勾选素材也不能混入。
- 地理标志、非遗身份、认证、奖项、年限、规模、销量、好评与排名要核对主体、范围、时间和来源。某项资质或规模不自动证明产品品质、功效或市场领先。
- 健康适用人群、美妆功效、安全承诺、季节最佳期、路线便利等主张须有对应依据。缺少证据时改为可确认的产品特点、体验项目或选择方法，不用占位符伪装已证实的效果。
- 四个字段按顺序各占一行。字段值上限依次为 **10、20、25、25 字**，四项字段值合计不超过 **80 字**；汉字、字母、数字、箭头和必要标点均计入。压缩时先去掉修饰词，保留推广对象、特色、支撑和价值之间的关系。
- 输出不得加入关键词分析、素材清单、推导过程、备选方向、平台标签、引用标记、寒暄或解释。

## 标准输出格式

核心宣发受众：[10字内，明确需求人群或受众兜底]
核心表达：[20字内，推广对象与单一特色价值]
内容切口：[25字内，特色资产 → 具体支撑 → 受众价值]
开场钩子：[25字内，与切口一致的具体信息或短句]

## 示例

以下示例只演示从诉求和已勾选素材推导品牌型思路的方法。示例输入不作为其他企业的事实来源；推导说明不得进入实际四行输出。

**示例一｜农产品：陕西青苹果**

诉求：推广陕西青苹果，让人记住酸甜脆爽的应季风味。已勾选素材：陕西青苹果、应季、酸甜脆爽。

推导：对象是区域产品，不补造企业品牌名。诉求指定风味，素材能支持“酸甜脆爽”，因此围绕这一项特色建立鲜果印象；不从产地推断营养或特殊人群适用性。

核心宣发受众：爱吃脆爽水果的人
核心表达：陕西青苹果以酸甜脆爽形成应季鲜果记忆
内容切口：陕西青苹果→酸甜脆爽→应季鲜果记忆
开场钩子：想吃酸甜脆口？看看陕西青苹果

**示例二｜非遗产品：鲁锦**

诉求：介绍鲁锦的传统织纹，突出在现代家居中的使用。已勾选素材：老木机织造、传统纹样、可用于茶桌布艺。

推导：从技艺和用途形成特色，不把“老”直接等同于品质，也不凭文案示例推定某家企业拥有非遗认定。

核心宣发受众：喜欢传统布艺的人
核心表达：鲁锦让传统织纹走进当代家居
内容切口：鲁锦→老木机织纹→茶桌上的传统美感
开场钩子：老木机织的纹样，铺上茶桌是什么样？

## 品类补充要点

- **农产品**：优先从有依据的品种、产地、时令、风味或食用方式中选一项可辨识优势。区域名称可以是推广对象，但不自动等于企业品牌；地理标志、营养和适用人群须单独核验。
- **文旅与非遗**：文旅从目的地的真实景观、活动或地方生活中提炼一项体验价值，不把景点列表压成“必打卡”口号；非遗从有出处的技艺、材料或纹样连接当代用途。非遗身份、历史和工序均须有依据。
- **日用品**：从材料、结构、触感、规格或服务中找受众能识别的日常优势。年限、仓储或销量可作背景证据，不能直接推出舒适、耐用或性价比。
- **美妆护肤**：可以从产品体系与需求对应关系建立选择认知；配方、测试或功效只有在已勾选素材提供对应证据时才可成为特色。促销档期与功效清单不能替代品牌定位。

## 输出前自检

- 是否先锁定本次诉求要建立的一个品牌认知，再从已勾选素材寻找支持？
- 推广对象的身份是否准确？企业品牌、区域产品、非遗技艺和文旅目的地有没有混淆？
- 核心表达是否只锚定一项具体特色，内容切口是否用相关细节解释其价值？
- 四字段是否分别回答“谁在意、记住什么、怎样说明、从何进入”，而非重复卖点？
- 认证、身份、功效、数据、比较和时效信息是否各有适用的证据？是否删掉无法支撑的强结论？
- 是否符合 **10、20、25、25 字**与总计 **80 字**上限，且只保留四行思路，没有写入正文组织方式？
