# 品牌型思路转译

## 任务目标

把工作台用户填写的【核心宣发诉求】与本次勾选的【企业素材库】转成品牌型思路大纲，只输出 **核心宣发受众、核心表达、内容切口、开场钩子**。优先转译客户提供的公司理念、产品理念、品牌优势及口号，让受众理解品牌相信什么、坚持什么，以及这些主张如何体现在产品或企业行动中；不写成稿、段落安排或平台玩法。

品牌型的目标是建立可辨识、可持续的品牌认知。产品特点可以作为品牌主张的支撑，但不默认把内容写成“解决什么麻烦、为什么值得购买”的种草思路。

本规则由四类真实传播案例的 **A（逆推的简短诉求）→ B（人工提炼的四字段）** 对照归纳。A 是训练推导方法的假设输入，不是已知的作者原始简报。真实工作台任务仍以当前客户输入和当前勾选素材为准，不能把案例中的品牌事实、热度或措辞带入新企业。

遵循总 README 的顺序：`真实素材 → 宣发目标 → 叙事模式 → 品类证据 → 平台结构 → 表达语调 → 风险校验`。在品牌型思路阶段，只进行前四项所需的目标识别、品牌主张提炼与证据判断；平台、语调和完整表达留给下游。

## 输入优先级

1. **客户输入的品牌信息决定方向**：优先提取本次诉求及客户新增、上传内容中的公司理念、产品理念、品牌定位、品牌优势、官方口号和传播限制。客户明确要求传达某项理念、优势或口号时，以此作为本次品牌主张的起点，不自行改选素材库里更容易写成产品推荐的亮点。
2. **已勾选素材说明主张如何落地**：只看当前勾选的企业材料，优先使用与客户输入相关的内容；再查找能体现该理念或优势的 1–2 项具体材料，如产品原则、工艺选择、企业行动或设计细节。推广对象可以是企业品牌、区域产品、目的地或有依据的技艺，不擅自补造品牌归属。
3. **证据决定主张的力度**：区分可核验事实、企业自述、主观体验和营销说法。客户提供的理念可以作为品牌自述表达，但不能仅凭理念推断企业已经取得某种效果；品牌优势涉及认证、性能或比较时，仍须有相应依据。

## 从 A 到 B：人工逆向拆解出的推导方法

四个案例呈现的共同方法不是复刻爆款句式，而是把原初关键词依次转为：**推广对象 → 本次要传达的品牌主张 → 能体现主张的具体依据 → 受众可记住的表达入口**。延安苹果的“征求建议”变成品牌态度，PMPM 的多款水乳变成按肤质挑选的方法，维达的纸巾婚纱把材料特性变得可见，山西古建让宽泛目的地有了明确的旅行主题。这些是案例中的推导关系，不是品牌型内容必须采用产品选择理由的模板，也不是其他企业可直接使用的事实。

### Step 1 从诉求和素材整理原初关键词

- **对象词**：品牌、产品、地方特产、目的地或技艺的准确名称。先确认“要让谁被记住”，避免将地方公共名称写成企业专有品牌。
- **理念词**：客户明确提供的公司理念、产品理念、品牌定位或长期坚持的原则。先保留其原意，再判断本次最需要传达哪一项。
- **优势词**：客户希望建立的品牌优势，以及能体现优势的产地、风味、材料、工艺、产品系列、景观、体验或真实行动。
- **口号词**：客户提供的官方口号、固定表述及其核心含义。不得自行编造官方口号，也不为追求文采改变原有承诺。
- **证据词**：能说明理念或优势如何落地的可见细节、流程、作品、标准、活动或资料来源。数据与认证须核对主体、范围和时间。
- **受众词**：诉求指定的人群，以及可能关心该理念或品牌主张的人；没有明确依据时，不凭空补出身份画像。
- **入口词**：与品牌主张相关的画面、动作、反差、提问或口号中的关键意象，只用于提炼钩子，不直接抄参考案例。

### Step 2 从多个关键词中选一个品牌锚点

- 先看客户本次指定的理念、优势或口号，再用“是否回应本次诉求、是否有已勾选素材支撑、是否容易被识别、是否适合形成长期品牌认知”筛选品牌锚点。只选一项中心主张，其他事实最多作为 1–2 个支撑细节。
- 优先追问“品牌主张是什么、它如何体现在产品或行动中、受众应记住什么”。产品的实用价值可以帮助解释品牌主张，但不能自动取代公司理念或产品理念。若客户没有提供理念类信息，再从有依据的产品特色中提炼较稳妥的品牌认知。
- 客户明确提供的品牌理念可以按企业自述转译；若缺少对应行动或产品依据，就保持为“主张、重视、致力于”等有边界的表达，不能写成已经实现的成果。
- 当诉求写“品牌特色”，但素材只有通用的品类名称或空泛形容时，缩小到最具体的已知特点；不能为了显得独特而编造“唯一、首创、最好”或攻击同类产品。

### Step 3 由品牌锚点推导四个字段

- **核心宣发受众**：先用诉求明确指定的人群；未指定时，判断谁会关注或认同该品牌主张。不要因为参考文案是学生党、女性或游客，就把相同身份套给当前企业。无法合理细分时用“泛消费人群”。
- **核心表达**：将推广对象与一项品牌理念、产品原则或有依据的优势绑定，回答“希望受众记住这个品牌相信什么、坚持什么”。客户指定口号且字数允许时，可保留其准确表述；字数不允许时，提炼其核心含义，不截断或冒充原口号。核心表达不写成产品参数清单或多个卖点并列。
- **内容切口**：说明用什么材料让品牌主张变得具体，优先压成“**品牌主张 → 产品原则或企业行动 → 品牌印象**”三个短语。若客户本次明确聚焦某项产品优势，也可沿用“特色对象 → 具体支撑 → 品牌认知”；不写正文展开次序。
- **开场钩子**：从同一个品牌主张及其依据里选最具体的入口，可用理念中的关键问题、真实行动、产品原则、可见场景或口号意象。钩子负责引出品牌认知，不能复制参考爆款的身份、事件或夸张结论，也不能另开一个与核心表达无关的卖点。

### Step 4 回查 A→B 是否有越界演绎

- 每个 B 字段的实质信息都应能追溯到本次客户输入或已勾选素材。合理推导可以将客户理念与已有产品原则联系起来，但不能将“重视品质”推出“品质行业第一”；可以把“古建可探访”转成“访古主题”，但不能推出“全国最美”。
- 若 A 中只是营销目的或作者的个人赞叹，不能自动变成客观品牌优势。若 A 缺少支撑某个主张的事实，保留更窄的特色，删掉无依据的结果。
- 四字段须共同指向一个品牌锚点，同时各回答不同问题。若去掉推广对象后仍可套在任何品牌上，重新寻找客户提供的具体理念、原则或行动；若内容主要在回答“为什么适合我、为什么值得买”，回查是否偏向种草型。

## 严格边界

- 只输出备忘录式四字段大纲。允许准确、自然、有具体信息的表达；不输出分析过程、原初关键词表、案例复述、冗长公司介绍、正文段落、A/B 版本、平台标签、购买指令或解释。
- 本次客户输入和当前勾选的企业素材是当前企业信息的来源；参考爆款仅用于学习“如何由 A 推到 B”。不得继承参考案例的产地、身份、情节、销量、价格、功效、营销档期或已取得的传播效果。
- “地理标志、非遗、认证、领先、第一、适合所有人、健康功效、安全效果”等主张须有相应证据。年限、仓储、奖项和互动量本身也不能自动证明产品质量或受众收益。
- 不把区域产品写成私有品牌，不把普通手作写成非遗，不把主观旅行评价写成客观排名。没有明确产品适用人群时，不虚构年龄、性别或身份。
- 四字段按顺序各占一行；字段值上限依次为 **10、20、25、25 字**，合计不超过 **80 字**。汉字、字母、数字、箭头及标点均计入。先删形容和重复，保留品牌对象、中心主张及关键依据。

## 标准输出格式

核心宣发受众：[10字内，谁关注该品牌主张]
核心表达：[20字内，品牌对象与单一理念或优势]
内容切口：[25字内，品牌主张 → 具体实践 → 品牌印象]
开场钩子：[25字内，与同一主张相关的具体入口]

## 品类补充要点

- **农产品**：优先看客户提供的种植理念、产品原则或品牌态度，再从已证实的品种、时令、风味、采收方式或真实生产行动中选支撑。产地是对象或证据，不自动推出品质；“听劝”“助农”等态度或结果需要真实行动支持。
- **护肤品**：优先看客户提供的研发理念、配方原则或品牌定位，再从配方依据、使用质地、产品系列与需求对应关系中选支撑。多系列能提供比较路径，不等于所有肤质适用或有统一功效；平价也不能在缺少价格比较时升级为“全网最低”。
- **日用品**：优先看客户提供的设计理念和产品原则，再用材料、结构或设计说明其如何体现在产品中。展示性作品可让材料特性可见，但不代表耐用、安全或功效已通过测试。
- **文旅与非遗**：优先看客户提供的文化主张、传承理念或目的地定位，再从有依据的景观、文化资源、技艺、工序、作品或参与活动中选支撑。地位、历史、认证与路线便利都要核对，不能将“最美、必去”等主观感受写成事实。

## 输出前自检

- 是否优先使用客户本次提供的公司理念、产品理念、品牌优势和口号，再选择当前勾选素材中的支撑？
- 推广对象的名称和身份是否准确？核心表达能否让人记住一个属于该对象的品牌主张？
- 产品特点是在说明品牌主张如何落地，还是已经取代品牌主张、变成单纯的购买理由？
- 内容切口是否包含真正能解释理念或优势的具体支撑？口号是否被准确理解，且没有被编造或曲解？
- 钩子是否从同一品牌主张长出，并有具体信息，而不是照搬参考帖的流行句式？
- A 中没有的功效、比较、身份、数据或结果，是否没有出现在 B 中？
- 四字段是否各自承担“谁、记住什么、凭什么、从何进入”，并满足 **10/20/25/25 字、合计 80 字**的限制？

## 逆向测试用法

使用品牌型 A→B 逆向测试样本中的四类案例时，将每例的 A 与“可用素材”输入思路转译，将生成结果同人工 B 比较。重点检查对象是否准确、锚点是否单一、支撑是否真实、受众和钩子是否由 A 推出；同时检查是否将品牌主张误写成单纯的产品推荐。允许不同措辞，不要求机械复刻标准答案。案例中的热度只说明选样理由，不进入工作台输出。
