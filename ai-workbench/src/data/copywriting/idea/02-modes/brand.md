# 品牌型思路转译

## 任务目标

把工作台用户填写的【核心宣发诉求】与本次勾选的【企业素材库】转成品牌型思路大纲，只输出 **核心宣发受众、核心表达、内容切口、开场钩子**。本阶段要让推广对象与一项可说明的特色建立清晰联系，并指出如何让受众理解这项特色的价值；不写成稿、段落安排或平台玩法。

本规则由四类真实传播案例的 **A（逆推的简短诉求）→ B（人工提炼的四字段）** 对照归纳，案例见 [品牌型 A→B 逆向测试样本](brand-reverse-test-cases.md)。A 是训练推导方法的假设输入，不是已知的作者原始简报。真实工作台任务仍以当前用户诉求和当前勾选素材为准，不能把案例中的品牌事实、热度或措辞带入新企业。

遵循总 README 的顺序：`真实素材 → 宣发目标 → 叙事模式 → 品类证据 → 平台结构 → 表达语调 → 风险校验`。在品牌型思路阶段，只进行前四项所需的目标识别、特色筛选与证据判断；平台、语调和完整表达留给下游。

## 输入优先级

1. **用户诉求决定本次要建立的认知**：先提取推广对象、传播目的、指定受众、希望突出的特色及限制。用户明确要求强调某个产品、工艺、地方资源或品牌行动时，不自行改选素材库中的其他亮点。
2. **已勾选素材决定可说的事实**：只看当前勾选的企业材料，优先使用与诉求相关的用户新增或上传内容；再查找能支持特色的 1–2 项具体材料。推广对象可以是企业品牌、区域产品、目的地或有依据的技艺，不擅自补造品牌归属。
3. **证据决定主张的力度**：区分可核验事实、企业自述、主观体验和营销说法。素材只能证明“有多个系列”时，可以提出“便于按需求比较”的思路，不能说每种肤质都适用；有作品展示时，也不能把作品当成全场景性能检测。

## 从 A 到 B：人工逆向拆解出的推导方法

四个案例呈现的共同方法不是复刻爆款句式，而是把原初关键词依次转为：**推广对象 → 最可辨识的特色 → 受众关心的选择理由 → 具体表达入口**。延安苹果的“征求建议”变成品牌态度，PMPM 的多款水乳变成按肤质挑选的方法，维达的纸巾婚纱把材料特性变得可见，山西古建让宽泛目的地有了明确的旅行主题。这些是案例中的推导关系，不是其他企业可直接使用的事实。

### Step 1 从诉求和素材整理原初关键词

- **对象词**：品牌、产品、地方特产、目的地或技艺的准确名称。先确认“要让谁被记住”，避免将地方公共名称写成企业专有品牌。
- **特征词**：与本次诉求相关的产地、风味、材料、工艺、产品系列、景观、体验或真实行动。它描述对象有什么、做了什么。
- **证据词**：能说明特征的可见细节、流程、作品、标准、活动或资料来源。数据与认证须核对主体、范围和时间。
- **需求词**：诉求指定的人群、使用需求、预算、选购难点或出游动机；没有明确依据时，不凭空补出身份画像。
- **入口词**：同一特征中最具体的画面、动作、反差、习俗或提问可能性，只用于提炼钩子，不直接抄原文。

### Step 2 从多个关键词中选一个品牌锚点

- 用“是否回应本次诉求、是否有已勾选素材支撑、是否容易被识别、是否能转成受众价值”筛选特色。只选一项主张，其他事实最多作为 1–2 个支撑细节。
- 把“产品有什么”追问为“受众为何会在意”。例如，多系列水乳可以帮助有不同需求的人比较选择；可展示的工艺或作品可以让抽象特点变得具体。推导只能到素材支持的程度，不能把便利、审美或可见性夸成未经证实的效果。
- 当诉求写“品牌特色”，但素材只有通用的品类名称或空泛形容时，缩小到最具体的已知特点；不能为了显得独特而编造“唯一、首创、最好”或攻击同类产品。

### Step 3 由品牌锚点推导四个字段

- **核心宣发受众**：先用诉求明确指定的人群；未指定时，从该特色解决的明确需求反推“谁最在意”。不要因为参考文案是学生党、女性或游客，就把相同身份套给当前企业。无法合理细分时用“泛消费人群”。
- **核心表达**：将推广对象与一项有依据的特色价值绑定，回答“希望受众记住谁的什么优势”。它是品牌认知目标，不是口号、产品参数清单或多个卖点并列。
- **内容切口**：说明将用什么材料让优势成立，优先压成“**特色对象 → 具体支撑 → 受众价值**”三个短语。第一项让对象可识别，第二项取自勾选素材，第三项回答受众为什么要在意；不写正文展开次序。
- **开场钩子**：从同一个特色及其证据里选最具体的入口，可用真实动作、用途反差、地方场景或一个容易回答的问题。钩子负责引发注意，不能复制参考爆款的身份、事件或夸张结论，也不能另开一个与核心表达无关的卖点。

### Step 4 回查 A→B 是否有越界演绎

- 每个 B 字段的实质信息都应能追溯到本次诉求或已勾选素材。合理推导可以把“多系列”解释为“有选择空间”，但不能推出功效；可以把“古建可探访”转成“访古主题”，但不能推出“全国最美”。
- 若 A 中只是营销目的或作者的个人赞叹，不能自动变成客观品牌优势。若 A 缺少支撑某个主张的事实，保留更窄的特色，删掉无依据的结果。
- 四字段须共同指向一个品牌锚点，同时各回答不同问题。若去掉推广对象后仍可套在任何品牌上，重新寻找具体特征或把主张缩窄。

## 严格边界

- 只输出备忘录式四字段大纲。允许准确、自然、有具体信息的表达；不输出分析过程、原初关键词表、案例复述、公司介绍、正文段落、A/B 版本、平台标签、购买指令或解释。
- 本次勾选的企业素材是当前企业事实的唯一来源；参考爆款仅用于学习“如何由 A 推到 B”。不得继承参考案例的产地、身份、情节、销量、价格、功效、营销档期或已取得的传播效果。
- “地理标志、非遗、认证、领先、第一、适合所有人、健康功效、安全效果”等主张须有相应证据。年限、仓储、奖项和互动量本身也不能自动证明产品质量或受众收益。
- 不把区域产品写成私有品牌，不把普通手作写成非遗，不把主观旅行评价写成客观排名。没有明确产品适用人群时，不虚构年龄、性别或身份。
- 四字段按顺序各占一行；字段值上限依次为 **10、20、25、25 字**，合计不超过 **80 字**。汉字、字母、数字、箭头及标点均计入。先删形容和重复，保留对象、特色、支撑与价值。

## 标准输出格式

核心宣发受众：[10字内，谁在意该特色]
核心表达：[20字内，对象与单一优势]
内容切口：[25字内，特色对象 → 具体支撑 → 受众价值]
开场钩子：[25字内，与同一特色相关的具体入口]

## 品类补充要点

- **农产品**：从已证实的品种、时令、风味、采收方式或真实生产行动中选一项可辨识特征。产地是对象或证据，不自动推出品质；“听劝”“助农”等态度或结果需要真实行动支持。
- **护肤品**：可从配方依据、使用质地、产品系列与需求对应关系中选锚点。多系列能提供比较路径，不等于所有肤质适用或有统一功效；平价也不能在缺少价格比较时升级为“全网最低”。
- **日用品**：把材料、结构或设计转成可以说明的日常价值。展示性作品可让材料特性可见，但不代表耐用、安全或功效已通过测试。
- **文旅与非遗**：目的地从有依据的景观、文化资源或参与活动中选一个旅行主题；非遗从已确认的技艺、工序或作品中选一个当代价值。地位、历史、认证与路线便利都要核对，不能将“最美、必去”等主观感受写成事实。

## 输出前自检

- 是否由当前用户诉求确定方向，再用当前勾选素材支持这一方向？
- 推广对象的名称和身份是否准确？能否用一项特色说明它为何值得被记住？
- 核心表达是否是单一品牌认知，内容切口是否包含真正能解释它的具体支撑？
- 钩子是否从同一特色长出，并有具体信息，而不是照搬参考帖的流行句式？
- A 中没有的功效、比较、身份、数据或结果，是否没有出现在 B 中？
- 四字段是否各自承担“谁、记住什么、凭什么、从何进入”，并满足 **10/20/25/25 字、合计 80 字**的限制？

## 逆向测试用法

使用 [品牌型 A→B 逆向测试样本](brand-reverse-test-cases.md) 中四类案例时，将每例的 A 与“可用素材”输入思路转译，将生成结果同人工 B 比较。重点检查对象是否准确、锚点是否单一、支撑是否真实、受众和钩子是否由 A 推出；允许不同措辞，不要求机械复刻标准答案。案例中的热度只说明选样理由，不进入工作台输出。
