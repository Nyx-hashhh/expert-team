# 故事型思路转译

## 任务目标

将用户在工作台填写的【核心宣发诉求】作为本次任务的方向，将当前勾选的【企业素材库】内容作为事实依据，转为供下游写手扩写的故事型思路大纲。故事型在本阶段只保留一条核心因果链：**具体起点 → 真实特征介入 → 状态变化**。起点可以是生活困扰、选择犹豫、体验期待、意外发现或真实的经营处境。输出是选题和表达方向，不是故事正文或分段写作方案。

遵循总 README 的顺序：`真实素材 → 宣发目标 → 叙事模式 → 品类证据 → 平台结构 → 表达语调 → 风险校验`。其中，素材先划定可说的事实范围，**用户诉求决定在这个范围内重点说什么**。本文件只负责故事型的思路选择；真实性与证据要求优先。只参考当前已确定的品类规则，不读取其他模式或无关品类文件。平台、语调和完整篇章结构留给下游成文阶段。

## 输入优先级

1. **先读核心宣发诉求，确定方向**：提取用户本次要推广的对象、最想传达的价值，以及明确写出的受众、场景、卖点和限制。用户说了重点，就围绕该重点生成思路；不要先浏览素材，再自行改选另一个卖点。
2. **再找相关素材，提供依据**：只看当前勾选的素材，优先使用其中由用户新增或上传、且与本次诉求相关的可用内容；再从其他已勾选素材补充。挑选 **1–2 个**最能支撑诉求的真实特征，如材料、工艺、产地、结构、服务方式或感官描述。无关信息即使详细，也不强行塞入大纲。
3. **最后核对事实边界**：区分可核验事实、企业自述与个人体验。诉求决定表达方向，但不自动证明诉求中的数据或效果。若素材不足以支持用户希望突出的某项主张，保留诉求中的合理场景与价值方向，改用有依据的特征和保守表述；不得转向素材里另一项无关优势，也不得补造证据。

## 从诉求与素材推导四字段

不要复述参考爆款的身份、情节或话术。其可复用的方法是：**诉求定方向，素材定事实，特征转利益，利益找起点**。将“产品有什么”先转为“使用者能感到什么差别”，再问“谁会在什么场景在意这个差别”，由此确定大纲思路。

### Step 1 确定本次诉求和故事起点

- 先锁定用户希望突出的一个价值。用户已明确提出受众、场景或起点时优先采用；没有写明时，再从该价值寻找一个具体处境。可选生活小麻烦、挑选时的犹豫、使用前的期待、发现产品的意外，或素材证实的生产与销售难题。
- 起点要贴合诉求与产品，不强加身份、购买经历、重大危机或戏剧化矛盾。无需每次都写“怕买错、缺点什么”：椅垫可以从硬椅上的一个动作切入，文旅可以从放慢脚步的期待切入，真实果农也可以从一批果子熟了却卖不动切入。

### Step 2 将素材特征转为用户利益

- 从已勾选素材中选 **1–2 个**同时贴合诉求与起点的特征，优先采用相关的用户新增或上传素材。
- 对每个特征追问：它带来什么可感知的使用差别？哪个受众会在什么情境下在意？例如“椅垫可套在硬椅上 → 改变坐在硬椅上的体验”；不能由结构直接推出未经证实的护腰功效。
- “接触产品的契机”只需说明使用或选择的合理节点。素材未确认的朋友推荐、旅行偶遇、购买记录不能当作事实。

### Step 3 只选一条因果线

- 在可能的起点中，只选最贴合用户诉求、能由勾选素材支撑、能指向具体变化的一条。不输出 A/B 切口。
- 视角随诉求和事实选择：可以是买家的发现、使用者的感受，也可以是生产者或店主的真实难处。若素材证实卖不出去、采收赶时间或备货压力，允许用“卖果犯愁”、轻微自嘲等有情绪的表达形成张力；不得把“卖惨”当通用套路，更不能编造滞销、亏损、亲友对话或助农成效。
- 结尾变化要回应同一个起点，以有依据的感官、动作或体验收束。个人感受不能扩写为普遍功效；不能仅凭“风景好、有历史”推出“独一无二、必须来”。

### Step 4 压缩为四字段

- **核心宣发受众**回答“谁在意这种需求”；按诉求确定，无明确指向时使用兜底值。
- **核心表达**回答“要让人记住什么单一价值”；说明借哪个具体起点表达哪项价值，不写情节经过。
- **内容切口**回答“用哪条因果线呈现”；用三个短语排列“起点 -> 产品契机与真实细节 -> 状态变化”，不扩写人物或情节。
- **开场钩子**回答“从哪个瞬间进入”；从已选切口提炼一句短话，可用真实处境直说、一个动作、意外反差、轻自嘲、对话感或提问。句式由诉求和素材决定，不必每次提问，也不必都写“怕什么、缺什么”。钩子要有具体信息或情绪张力，不另开故事，不写正文段落。四个字段不得换词重复同一句卖点。

## 严格边界

- 只输出备忘录式大纲。允许贴合事实的口语、轻微情绪与自嘲，让思路有生气；禁止成文、分幕、场景铺陈、人物塑造、抒情、排比、比喻堆砌、空泛形容和无依据的强推销语。
- 只使用本次勾选的企业素材，不把未勾选素材或参考爆款文案当作当前企业的事实来源。用户填写的核心诉求是任务指令，其中涉及的事实主张仍须与素材核对。不虚构人物经历、产地、历史、原料、价格、规格、销量、评价、功效或前后对比。
- 素材未给出但确需保留的重量、价格、年份等具体数据，用 `[具体参数]` 占位。缺少结果证据时不能用占位符伪装效果已成立，应改为保守的观察点。
- 仅在诉求或产品明确指向人群时填写具体受众；否则填写“泛消费人群”。
- 四个字段按顺序各占一行。字段值上限依次为 **10、20、25、25 字**，四项字段值合计不超过 **80 字**；箭头及必要标点计入。压缩时先删修饰，不删因果和证据边界。
- 输出中不得加入分析过程、素材清单、备选方案、平台标签、引用标记、寒暄或解释。

## 标准输出格式

核心宣发受众：[10字内，具体场景人群或受众兜底]
核心表达：[20字内，具体起点与单一核心价值]
内容切口：[25字内，具体处境 -> 产品契机与真实细节 -> 状态变化]
开场钩子：[25字内，与切口一致的事实、动作、反差或短句]

## 示例

以下两个示例演示不同起点与视角。示例输入仅用于说明推导，实际任务只使用用户本次诉求和已勾选素材；示例中的推导说明不得进入四行输出。

**示例一｜农产品：山野现采**

诉求：推广山野橙子，突出鲜采与鲜甜口感。已勾选素材：山野现采、果肉甜美。

推导：诉求强调鲜采与鲜甜，素材能支持采摘和口感细节，因此从想尝鲜采水果的期待切入，以剥开品尝形成变化。不额外编造果农身份或卖果困难。

核心宣发受众：喜欢鲜采水果的人
核心表达：借现采到入口，突出橙子的鲜甜
内容切口：想尝鲜采橙 -> 看山野现采 -> 尝甜美果肉
开场钩子：山野里的橙子摘下来了，先剥一个

**示例二｜文旅**

诉求：推广济南周末慢游，突出泉水与老街的地方生活感。已勾选素材：可步行串联的泉水点和老街路线。

推导：诉求强调慢游，路线素材能支撑步行体验，因此从“想走慢一点”的期待切入，不额外宣称景点免费、独一无二或必去。

核心宣发受众：想周末慢游的人
核心表达：借周末慢游突出泉水老街体验
内容切口：周末想慢游 -> 走泉水老街 -> 慢逛街巷
开场钩子：这次去济南，先把赶路计划划掉

## 品类补充要点

- **农产品**：优先把有依据的时令、采收、口感或食用方式转为购买与品尝理由；有真实生产或销售压力时，可用卖方视角与适度自嘲，不必一律从买家“怕踩雷”切入。不从产地直接推断品质，不虚构滞销、助农成效或统一甜度。
- **美妆护肤**：从诉求指定的肤感、香气、使用场合或送礼期待中选一个起点，用有依据的质地、气味或体验回应。不能由“提升生活质量”自动窄化为“精致女性”，也不能照搬参考文案中的功效。
- **日用品**：将材料或结构转为具体动作上的便利，再找到相应的使用场景；结尾只写可观察的差别。承重、耐用、护腰等功效须有证据，不把销量当成产品利益。
- **文旅与非遗**：先从用户诉求提炼共同的出游动机，再从已勾选素材中选一项最有辨识度的真实景观、地方文化或参与体验，推导它对旅行者的具体好处。受众按共同动机概括，不因“带娃、陪长辈”等单个场景强行窄化。切口可从发现特色、体验反差、文化兴趣或地方生活切入；素材含真实游览感受时，也可用旅行者分享经验的安利口吻，但不作为默认写法，不伪装亲历。非遗身份、历史和工序须有依据，钩子不套用“必来、封神、独一无二”。
  - **文旅路线补充｜仅在用户提供路线时启用**：路线可来自本次诉求或已勾选素材。分析节点组合及用户明确描述的连接方式，选出最贴合诉求、对旅行者最有价值的一项好处；在内容切口中用1–2个关键节点支撑，不复述整条路线。没有路线时按上方主规则生成，不自行规划路线；缺少距离、用时、费用或客流依据时，不宣称省时、省钱、少折返或清静。

## 输出前自检

- 四行是否围绕同一个具体处境，形成“起点 → 特征 → 变化”的因果链？
- 核心表达和内容切口是否首先回应用户本次填写的诉求，而不是被素材库中其他亮点带偏？相关的用户新增或上传素材是否已优先使用？
- 每个产品特征和结果是否都能追溯到本次勾选素材，主张是否符合证据等级？
- 四个字段是否各回答不同问题，只选一个切口、1–2 个核心特征，并符合字段与总字数上限？
- 钩子是否与切口一致且有具体信息？是否机械重复“怕、缺、总觉得”或一律写成疑问句？
- 是否删尽人物设定、文学化铺陈和篇章指导，只留下可供下游扩写的思路？
