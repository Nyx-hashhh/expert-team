# 02｜思路模式

思路模式决定四字段大纲的推导角度，不负责正文结构、平台表达或语调。一次任务只读取一个模式文件。

| 模式 | 推导核心 | 四字段应形成的关系 |
| --- | --- | --- |
| [故事型](story.md) | 生活冲突、转折契机与状态变化 | 痛点场景 → 产品契机与真实细节 → 体验或状态改变 |
| [种草型](seed.md) | 实用需求、硬核卖点与决策价值 | 使用需求 → 2 个事实亮点 → 入手价值与边界 |
| [品牌型](brand.md) | 品牌取舍、真实投入与差异信任 | 真实问题或取舍 → 品牌投入与细节 → 诚意或稀缺提醒 |

三个模式统一采用 `Role → Instructions → Constraints → Few Shot` 结构，但内部推导公式必须明显不同。本阶段必须把结果压缩为“核心宣发受众、核心表达、内容切口、开场钩子”四项，字段上限依次为 10 / 20 / 25 / 25 个汉字，内容合计不超过 80 个汉字。完整正文、平台改写、语调、分镜、标签和 A/B 版本统一交给 `post` 阶段。

通用推导步骤与字数边界见 [从简短输入到思路大纲的实操方法论](../01-methodology/from-brief-to-outline.md)。
