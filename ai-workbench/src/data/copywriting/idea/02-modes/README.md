# 02｜思路模式

思路模式决定四字段大纲的推导角度，不负责正文结构、平台表达或语调。一次任务只读取一个模式文件。

| 模式 | 推导核心 | 四字段应形成的关系 |
| --- | --- | --- |
| [故事型](story.md) | 代表人物、具体场景、真实阻力与变化 | 受众对应人物 → 核心变化 → 关键事件切口 → 入戏钩子 |
| [种草型](seed.md) | 使用需要、选择标准、事实证据与适用边界 | 需要判断的人 → 选择结论 → 使用或比较切口 → 问题钩子 |
| [品牌型](brand.md) | 品类定锚、差异事实、可信行动与用户价值 | 目标认知人群 → 品牌结论 → 信任切口 → 差异钩子 |

本阶段必须把推导结果压缩为“核心宣发受众、核心表达、内容切口、开场钩子”四项。完整正文、平台改写、语调、分镜、标签和 A/B 版本统一交给 `post` 阶段。

通用推导步骤与字数边界见 [从简短输入到思路大纲的实操方法论](../01-methodology/from-brief-to-outline.md)。
