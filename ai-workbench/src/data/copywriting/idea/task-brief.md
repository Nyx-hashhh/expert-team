# idea 阶段输入整理清单

本清单只用于把简短诉求整理成第一阶段可用输入，不负责生成最终文案。

## 已知信息

1. **原始诉求**：保留用户原话，不先扩写。
2. **核心对象**：本次推广的具体产品、服务、活动或品牌。
3. **传播目标**：希望受众知道、理解、比较、尝试还是购买。
4. **所选模式**：故事型、种草型或品牌型，只选一个。
5. **真实素材**：与本次诉求直接相关的产品、品牌、场景和证据，最多先选三项。
6. **明确限制**：用户已经给出的合规、字数、禁用信息或时间要求。

## 缺失信息

- 哪些内容尚未提供，不能作为事实写入？
- 哪些卖点只有企业自述，尚无外部或内部材料支持？
- 是否缺少判断受众、核心表达或内容切口所需的关键信息？

缺失信息不靠猜测补齐。若不影响最小可行思路，可使用保守表达；若会改变核心方向，应先提示用户确认。

整理完成后，进入 [从简短输入到思路大纲的实操方法论](01-methodology/from-brief-to-outline.md)。
