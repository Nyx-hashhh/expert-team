# 02｜叙事模式

叙事模式决定全文的说服机制，优先级高于平台和语调。

| 模式 | 核心问题 | 基本骨架 |
| --- | --- | --- |
| [故事型](story.md) | 如何让卖点通过具体案例被感受和记住？ | 开端 → 发展 → 高潮 → 结局 → 尾声 |
| [种草型](seed.md) | 如何让用户通过可信体验判断是否适合自己？ | 需要 → 选择 → 使用 → 感受 → 适配 → 边界 |
| [品牌型](brand.md) | 如何让品牌在同类选择中被优先想起和信任？ | 品类定锚 → 差异 → 专业 → 权威 → 利益 → 记忆 |

一次内容只选一个主模式。其他模式只能作为辅助：故事型可以包含使用体验，但不能失去五幕叙事；品牌型可以讲创始故事，但最终必须回到品牌心智与可信证明。
