# 宣发文案规则库

本目录按“先确定大逻辑，再决定具体表达”的顺序组织。写作时从上至下选取规则，不应先选平台热词，再反向拼凑内容。

## 规则层级

1. **基础层**：确定真实边界、证据要求和宣发目标。
2. **叙事模式层**：选择故事型、种草型或品牌型，决定说服路径和全文骨架。
3. **品类层**：根据农产品、非遗产品、美妆或日用品，决定应写哪些事实、使用什么证据、规避什么风险。
4. **平台层**：把同一核心内容改写为平台原生的信息结构和互动方式。
5. **语调层**：调整人与人的距离、专业程度、节奏和情绪浓度，不改变事实与逻辑。
6. **组合层**：把以上规则合成为一份创作简报，并完成冲突检查和成稿自检。

## 唯一正确的组合顺序

`真实素材 → 宣发目标 → 叙事模式 → 品类证据 → 平台结构 → 表达语调 → 风险校验`

叙事模式的优先级高于平台和语调。例如，“品牌型 + 抖音 + 年轻活力”仍须先完成品牌定锚、专业证明和权威证据，再用短视频节奏及年轻语言表达；不能因为平台或语调而退化成泛娱乐内容。

## 快速示例

“为高山春茶写一篇小红书闺蜜安利文案”应拆解为：

- 模式：种草型——真实人物体验、适用场景与边界。
- 品类：农产品——产地、品种、采摘、发货、口感和储存证据。
- 平台：小红书——生活场景、体验步骤、可收藏的信息结构。
- 语调：闺蜜安利——亲近口语，但不伪造购买经历或夸大效果。

最终产物不是四段规则的简单相加，而是一条完整因果链：为什么需要 → 为什么选择 → 怎样体验 → 什么事实证明 → 适合谁 → 下一步如何行动。
