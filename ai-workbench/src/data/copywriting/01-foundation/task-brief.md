# 宣发任务拆解

生成内容前先回答以下问题：

1. **传播对象**：谁会看到这条内容，其审美、信息需求和阅读耐心如何？
2. **传播目标**：需要被记住、被理解、被比较、被尝试，还是被购买？
3. **核心对象**：推广哪项产品、服务、活动或品牌资产？
4. **单一主张**：用户看完后只能记住一件事，应是什么？
5. **事实支撑**：哪三项以内的事实最能证明这件事？
6. **行动阶段**：用户处于初次认识、考虑比较、准备购买还是复购分享？
7. **限制条件**：平台、字数、语言、合规、时间、预算与素材缺口是什么？

输出简报时使用：

`向[宣发受众]，在[平台/场景]，用[叙事模式]和[表达语调]，通过[核心事实]证明[单一主张]，促使其完成[下一步行动]。`
