# 真实性与证据

## 事实分级

1. **已验证事实**：企业资料、检测、认证、合同、平台后台、公开权威来源，可直接使用并标注口径。
2. **企业自述**：可写成“品牌表示、团队介绍”，不能自动升级为行业事实。
3. **个人体验**：只能代表具体人物、时间和条件，不能推广为普遍结果。
4. **创意表达**：可用于比喻、意象和节奏，不得创造人物经历、效果、排名或历史。

## 证据与句子对应

- 产品卖点 → 参数、材料、工艺、流程或真实使用细节。
- 功效结果 → 合规测试、适用条件、周期与个体差异。
- 专业性 → 团队、研发、标准、时间投入和持续行动。
- 权威性 → 认证、检测、奖项、专利或第三方数据的完整出处。
- 排名第一 → 品类、渠道/地区、统计周期、样本口径、发布主体和日期。
- 用户认可 → 真实评价来源、样本范围与授权，不拼接或伪造评价。

## 素材不足时

- 将绝对判断改为可证明的事实。
- 将普遍效果改为特定人物的主观感受。
- 将“最好、第一、唯一”改为具体参数、标准或行动。
- 明确列出需要用户补充的证据，暂不生成相关断言。

## 通用禁区

不虚构人物、购买记录、研发挫折、使用天数、前后效果、销量、奖项、认证、用户评价和实时热榜；不使用“赋能、引领、匠心打造、重新定义”等空泛套话。
